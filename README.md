# java-racingcar-precourse

## 자동차 경주 게임

- ### 구현할 기능

  - 자동차 클래스를 구현한다.
  - [x] 필드에는 이름과 전진한 횟수를 포함한다.
  - [x] 이름의 유효성을 검사하는 메서드를 구현한다.
  - [x] 전진 및 전진 여부를 계산하는 메서드를 구현한다.
  - [x] 전진 횟수만큼 -를 출력하는 메서드를 구현한다.


- [x] 입력값을 받아 자동차 객체를 생성한다.
- [x] 입력받은 횟수 만큼 자동차의 전진 메서드를 반복 실행한다.
- [x] 최종 우승자를 계산하여 출력한다.
